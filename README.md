- 🔭 En dehors du code, je suis passionné d'**astronomie** et plus particulièrement d'**astrophysique**.
- 📚 Actuellement en cours (pas mal chargés), donc je n'ai pas toujours le temps de sortir de grosses mises à jour — mais je reste dispo pour des petites choses.
